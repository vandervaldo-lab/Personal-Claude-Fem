# Meu Treino Feminino — PWA v2.2

Aplicativo web progressivo (PWA) do programa de treino feminino.  
Funciona offline, pode ser instalado na tela inicial do celular e salva os registros de RIR localmente.

---

## 🚀 Como publicar no GitHub Pages

### 1. Crie um repositório no GitHub
1. Acesse [github.com](https://github.com) e faça login
2. Clique em **New repository**
3. Nome sugerido: `meu-treino-fem`
4. Marque como **Public**
5. Clique em **Create repository**

### 2. Faça o upload dos arquivos
1. Na página do repositório, clique em **uploading an existing file**
2. Arraste **todos os arquivos da pasta** (incluindo a pasta `icons/`):
   - `index.html`, `style.css`, `data.js`, `app.js`
   - `sw.js`, `manifest.json`, `README.md`
   - Pasta `icons/` com `icon-192.png` e `icon-512.png`
3. Clique em **Commit changes**

### 3. Ative o GitHub Pages
1. Vá em **Settings → Pages**
2. Em **Source**, selecione `Branch: main / root`
3. Clique em **Save**
4. Aguarde 1–2 minutos

O app estará em:
```
https://SEU_USUARIO.github.io/meu-treino-fem/
```

### 4. Instale no celular
- **Android (Chrome):** Menu → Adicionar à tela inicial
- **iPhone (Safari):** Compartilhar → Adicionar à Tela de Início
